## **Brief Project Description**
This is the repository for the asynchronous laboratory activity #2 / group project, where we did an automation testing of 26 test cases using this website: 'https://automationexercise.com/'.

## **Technologies Used**
- Java
- Maven
- Selenium
- Visual Studio Code

## **Instructions on How to Set Up and Run the Project**
1. Make sure 'Java' and 'Maven' are **installed** in your PC and already in the **environment variables**.
2. If you're going to **use VS Code**, install '**Extension Pack for Java**'.
3. Clone the repository: '**https://github.com/keshi1i1/STA-Automation-Exercise.git**'.
4. Right-click the file: '**AutomationExerciseTestCases**' in the src/test/java/regression folders.
5. In the following choices, select '**Run Tests**' in order to run all the automated test cases.
